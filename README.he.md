# שחף מערכת שעות ל-Home Assistant

אינטגרציה לא רשמית לאפליקציה `com.shahafsoft.timetableapp`.
החיבור ישיר לשירות שחף, ואין צורך להשאיר טלפון מחובר.

## התקנה

ב-Home Assistant ‏2026.11 ומעלה: **הגדרות → Marketplace → הוספה מקישור**,
הזינו `https://github.com/NirBY/ha-shahaf` ובחרו הוספה והתקנה.
ה-Marketplace מחליף את HACS בגרסאות אלה.

[פתיחה ב-Marketplace](https://my.home-assistant.io/redirect/marketplace_repository/?owner=NirBY&repository=ha-shahaf&category=integration)

ב-HACS: בתפריט **⋮ → מאגרים מותאמים אישית**, הוסיפו את
`https://github.com/NirBY/ha-shahaf` מסוג **Integration**, התקינו והפעילו מחדש
את Home Assistant. המאגר אינו מופיע עדיין בקטלוג ברירת המחדל של HACS.

אפשר גם להעתיק את `custom_components/shahaf` אל
`/config/custom_components/shahaf` ולהפעיל מחדש.

לאחר מכן: **הגדרות → מכשירים ושירותים → הוספת אינטגרציה → Shahaf Timetable**.
הזינו סמל מוסד, שם משתמש וסיסמה, בחרו בית ספר וכיתה והגדירו תווית.
לכל כיתה נוספת מוסיפים חיבור נוסף. נדרשת גרסת Home Assistant ‏2026.2 ומעלה.

## המידע המוצג

### יומנים

לכל כיתה יש יומנים נפרדים: **מערכת שעות**, **שינויים** ו־**אירועים**.
כדי להציג בדשבורד רק שינויים וביטולים, בוחרים את יומן **שינויים** של כל כיתה.
יומן **אירועים** כולל אירועים ומבחנים. היומן המשולב **כל המידע** נשאר זמין.
כותרות הסוגים מוצגות לפי שפת Home Assistant: **עדכונים**, **אירועים**, **שינויים**
בעברית, או Updates, Events, Changes באנגלית. הטקסט המקורי מבית הספר נשמר.
בשפה ללא תרגום נעשה שימוש באנגלית. השפה נקבעת בשרת ומשותפת לכל המשתמשים.
יומן כל המידע כולל שיעורים, מבחנים, אירועים, שינויי מערכת וביטולים, והודעות
מתוארכות. התיאור שומר את הטקסט המקורי ואת מספרי השיעורים. שיעור ללא שעות
צלצול מוצג כאירוע יומי; הודעות ללא תאריך מצורפות לתיאורי האירועים בלי להמציא תאריך.

היומנים מופיעים אוטומטית במסך **לוח שנה** של Home Assistant. בדשבורד מוסיפים
לכרטיס היומן את סוג היומן הרצוי של כל כיתה דרך בורר הישויות. כדי למנוע כפילויות,
אין צורך לבחור באותו כרטיס גם את היומנים הנפרדים. מוצגים רק תאריכים שפורסמו.

### התראת ביטול ב־WhatsApp

[ייבוא Blueprint להתראות GreenAPI](https://my.home-assistant.io/redirect/blueprint_import/?blueprint_url=https%3A%2F%2Fraw.githubusercontent.com%2FNirBY%2Fha-shahaf%2Fmain%2Fblueprints%2Fautomation%2Fshahaf%2Fcancellation_greenapi.yaml).
יוצרים אוטומציה לכל כיתה ובוחרים חיישן שינויי מערכת, שם ילד/כיתה, מספר טלפון
בפורמט בינלאומי ללא פלוס ופעולת התראה קיימת, כברירת מחדל `notify.greenapi`.
נדרש GreenAPI מוגדר מראש. רק הודעות ביטול מפורשות חדשות או ששונו, להיום והלאה,
נשלחות. רענון זהה אינו שולח שוב. ההפעלה הראשונית קובעת נקודת התחלה, ללא השלמת
הודעות שפורסמו בזמן ש־HA היה כבוי. הודעה שנערכה או פורסמה מחדש עשויה להישלח שוב.

מערכת מתוארכת לשבוע הנוכחי והבא, שיעורי היום ומחר, שינויי מערכת,
מבחנים, אירועים והודעות. בנוסף נוצרים לוח שיעורים, לוח אירועי בית הספר
וכפתור רענון. ברירת המחדל היא רענון כל 15 דקות.

זו מערכת כיתתית הכוללת קבוצות מקבילות, ולא מערכת אישית של תלמיד.
הטקסט וההערות של בית הספר נשמרים. האינטגרציה אינה מנחשת לאיזו קבוצה
התלמיד שייך ואינה מבטלת קבוצות אוטומטית בעקבות הודעה עמומה.
אירועים ושינויים משויכים לשעות מערכת השעות כשפורסם טווח שיעורים חד־משמעי
וכל שעותיו זמינות לאותה כיתה ותאריך. אירוע שהוגדר לכל היום או שחסרות לו שעות
נשאר יומי. מספרי השיעורים והטקסט המקורי נשמרים בתיאור.

בעת תקלה הנתונים מסומנים כלא זמינים, ולא כ״אין שיעורים״. פרטי ההתחברות
נשמרים ב-Home Assistant ואינם מופיעים בקוד או באבחון.

האייקון המקורי של אפליקציית שחף כלול באינטגרציה ומוצג ב-Home Assistant
מגרסה 2026.3 ומעלה. בדיקת Brands של HACS מופעלת; אין צורך באישור נפרד
במאגר Brands עבור האייקון המקומי. האייקון שייך לחברת שחף ומשמש לזיהוי השירות.
